# Dynamic Resource Editor for MTA:SA v3.0

⚠️ **Disclaimer:** This tool was 100% generated by AI (Google's Gemini).

Dynamic Resource Editor (DRE) is a professional-grade, real-time In-Game IDE and file manager for Multi Theft Auto: San Andreas. It brings a VS Code-like development experience directly into the game, allowing developers and mappers to create, edit, manage, and inspect game elements in real-time.

## 🚀 Key Features & v3.0 Updates

* **🎨 Modernized UI & Theming System:** Choose from multiple built-in color themes and apply custom accent colors and background dimming directly via Preferences.
* **🎯 Select Object Mode:** Capture object data directly in-game. Toggle the mode, point your crosshair at any object or custom marker, and click to inspect its properties (Position, Rotation, Model ID, etc.) in a dedicated inspector tab.
* **📂 Enhanced File Management & Multi-Selection:**
    * **Multi-Selection:** Hold `CTRL` to select multiple files simultaneously in the explorer.
    * **Batch & Direct Copying:** Upgraded copy window featuring real-time search, category filters (**All, Maps, Scripts, Shaders**), and a **Recent Targets** quick-access bar highlighting your 5 most recently edited resources.
* ** Tab & Workspace System:** Edit multiple files simultaneously with an intuitive tabbed interface.
* **Smart File Manager:** Create, delete, rename, or copy files. The `meta.xml` is automatically updated and maintained.
* **Backup & Recovery:** Robust timestamped backups and an instant "Restore" mechanism linked to historical activity logs.
* **Activity Audit Logs:** Detailed history of all save, create, rename, and delete operations stored in `logs.db`.
* **Template Injector:** Easily insert code snippets (e.g., Jump Markers, Teleports, SlowMo, Custom Modifiers) directly into your scripts.
* **Embedded Auto-Updater:** Keep your tool updated effortlessly using the built-in update button located directly in the titlebar.
* **Account-Based Persistence:** All user preferences, themes, font sizes, and custom keybinds are saved individually per account via SQLite.

## ⚠️ Security & Requirements

**CRITICAL:** This tool provides read/write access to your server's file system.

**ACL Permissions:** Ensure the resource is added to the "Admin" group in your `acl.xml`:
  `<object name="resource.DynamicResourceEditor" />`
  
**Access Control:** Logged-in ACL Admins have full editing capabilities. Non-admins and guests can safely inspect resources and files in a cursorless **Read-Only Mode**.

## 📥 Installation

1. Clone the repository or download as `.zip`.
2. Extract the folder into your server's `resources` directory.
3. Ensure the folder name is exactly `DynamicResourceEditor`.
4. Add the resource to your `acl.xml` (see Security Warning).
5. Start the server, type `refresh`, and then `start DynamicResourceEditor`.

## 🎮 Usage

* **Toggle Editor:** Press `F2` in-game to open/close the IDE.
* **File Management:** 
    * **Left-click:** Select a file (`CTRL + Click` for multi-selection).
    * **Right-click:** Open the Context Menu (Copy, Rename, Delete).
* **Editing:** Double-click a file to open it in a new tab.
* **Saving:** Click "Save File" in the toolbar or use `Ctrl + S`.
* **Backups:** Open the **Backups** panel (`↺`), locate the desired version, and click "Restore".
* **Templates:** Use the "Templates" dropdown to inject code snippets at your cursor position.

*Note: This editor is in active development. If you encounter errors, check your server console for logs!*
